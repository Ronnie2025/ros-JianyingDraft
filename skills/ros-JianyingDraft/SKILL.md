# 剪映草稿转换

接收已经确定的剪辑决定，把素材、切点、轨道、文字与支持的参数写成剪映草稿。输出草稿目录、转换清单、素材依赖清单和验证报告。

## 适用边界

- 输入可采用文字说明、表格或结构化清单；先依照 [输入格式](references/input-format.md) 做字段归一化和确定性计算。
- 输入已经明确的内容直接沿用。缺少切点、目标位置、画幅、声音关系或关键样式时，集中列出会影响转换的缺项，不补做剪辑决定。
- 已有 MP4 可以用于核对呈现。只有合成视频时，说明仍缺哪些源素材和分层数据；不推测原剪辑或宣称可以恢复内部文字、动效层。
- 第一版每次新建独立草稿。当前工程的增量修改、人工改动合并与加密工程解析不在支持范围。
- 不执行自动转写、镜头取舍、节奏优化、叙事重排、字幕改写、素材生成、效果创作、降噪、响度优化或成片导出。

## 转换不变量

1. 保留给定顺序、时间、文字、空隙与跨轨重叠，不用自动吸附或填空改变方案。
2. 视频默认引用完整源文件，以源时间范围决定当前裁切，保留原素材前后内容。预先裁成短片的源文件只能提供该文件实际包含的范围。
3. 明确视频原声、独立人声和配乐的启用、静音与时间映射，依输入写入，不自行拆音轨或调整声音策略。
4. 字幕注明源素材时间或成片时间；按指定切点与速度转换，不改字、合并或另行断句。跨越未使用源范围的字幕先报告歧义，不猜测删留。
5. 原生文字保留改字、位置和时长能力。图片与预制透明视频作为独立素材，说明内部像素和动画的可编辑范围。
6. 只写入已经支持的效果。必需效果无法可靠表达时停止完整交付，保留转换清单并报告阻塞；不擅自替换或预渲染。可省略项也须由输入明确允许。
7. 素材登记记录路径、大小和校验值。路径重定位只接受明确映射，并核验素材身份，不用同名文件自动替代。
8. 使用新工程 ID 和独立目录，保留已有草稿及列表条目。同名生成新版本，不覆盖人工工程。

## 执行流程

### 1. 归一化与环境检查

读取 [输入格式](references/input-format.md)，将输入整理为转换清单。仅追问影响结果的缺项。若请求仍需创作剪辑方案，说明本 Skill 所需的确定信息并停在转换入口。

首次使用或环境变化时读取 [Mac 兼容说明](references/mac-compatibility.md)。通过应用标识识别国内剪映并记录实际版本，不能根据相似应用名选中 CapCut。检查固定依赖与媒体工具；使用 `scripts/setup_runtime.sh` 配置独立运行环境，默认位于 `~/.cache/ros-JianyingDraft/venv`，可通过 `JDC_RUNTIME` 指定运行环境位置。依赖安装失败时报告具体失败，禁止静默换上游版本。

### 2. 检查与生成

使用独立环境的 Python 执行以下命令。`PLAN` 为转换清单，`DIR` 为新的交付目录，`MAP` 为明确路径映射，`ROOT` 为明确草稿根目录：

```text
python scripts/converter.py check PLAN [--path-map MAP]
python scripts/converter.py build PLAN --output DIR [--path-map MAP]
python scripts/converter.py verify DIR
python scripts/converter.py install DIR [--draft-root ROOT]
```

`build` 输出 `draft/`、`conversion-plan.json`、`dependencies.json` 和 `validation.json`。具体字段见输入格式；可通过各子命令 `--help` 查询参数。

先运行 `check`，核对素材身份、源范围、速度、目标时间、图层和必需参数。全部必要项可转换后，运行 `build` 在独立目录生成完整时间线和伴随报告。结构验证失败时保留诊断，不安装失败草稿。

### 3. 安装与应用检查

检查通过后用 `install` 登记为新草稿。遵守应用状态与列表备份要求；应用正修改列表或无法安全登记时，先交付生成目录与具体安装阻塞。

运行 `verify` 核对工程结构及源清单一致性。随后依 [回归与验收](references/regression-cases.md) 在剪映中检查适用的编辑行为。只在独立测试草稿上试改、拖边，避免把验收动作留进用户最终时间线。

### 4. 交付

报告草稿与伴随文件的绝对路径、目标应用及版本、安装状态、素材是否仍依赖原位置、可编辑元素和未支持项。分别说明结构检查、应用内编辑、声音和画面检查的实际结果。

完整转换须核对完整时间线。短测试片只证明相应能力的兼容性。未经应用内验证时，明确写出该项尚未验证；历史记录和可解析 JSON 均不能替代本次证据。

## 停止条件

源素材缺失或身份不符、决定剪辑结果的信息缺失、必需效果不支持、目标应用版本未经兼容验证且打开失败、当前工程无法安全保留时，停止受影响步骤并报告具体缺项或失败。已经明确授权的转换无需重复确认。技能不承担修复用户原素材、覆盖旧工程或发布远端项目。
