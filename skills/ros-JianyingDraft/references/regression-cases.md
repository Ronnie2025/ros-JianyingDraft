# 回归与应用内验收

本文件列出转换结果的结构检查与应用内验收方法。

## 需要关注的转换问题

检查源素材是否保留拖边余量、音画裁切是否一致、预制图层是否包含不应保留的背景，以及文件移动后的链接状态。效果参数存在不能证明目标应用已经正确显示。

同期人声／人物小窗还要按 [声画编辑单元](edit-units.md) 检查拖动后同步，而不只检查初始摆放。

## 声画编辑关系回归

- 普通口播：默认视频自带声音，无未经明确要求拆出的同源人声音轨。
- 口播＋多图层／音量处理：仍保持同期声归属于视频；已导出的处理 WAV 不被误认作独立旁白。缺少带声派生视频或可靠关联时，报告输入缺项，不偷偷丢掉已确认的声音处理。
- 人物全屏切圆窗：优先同一人物主轨按确定区间呈现；独立圆窗方案必须在只选主片段移动后，证实人物、人声和字幕仍对应同一时刻。
- 反例：静音主视频、独立同源人声、无关联圆形人物初始对齐。即使结构检查通过，也不能以联动开关或字幕批次字段判为编辑同步通过。
- 明确分离：用户指定独立同期音轨，或素材本来是配音／配乐／音效时，保留明确分轨，不强制合并。
- 明确独立小窗：用户指定人物层独立且无需随主轨移动时保留其决定；不默认拆走该片段的同期声音，也不承诺它随主轨同步。
- 能力边界：未支持原生蒙版、主轨指定或组合时，不杜撰 JSON 字段，也不把静态说明当作功能实现。
- 移动、保存重开、删除、分割、拖边和变速分别记录结果；只实测移动时，其余保留未验证。

## 结构与一致性检查

- 对照转换清单核对完整时间线时长、片段数量、顺序、源时间范围、目标位置、速度、文字和图层。
- 源时间不越界；时间单位换算一致；明确区分结束位置与持续时长，避免将目标时长再次乘除速度。
- 给定空隙和跨轨重叠保留。若同轨重叠无法表达，报告具体片段和冲突，不擅自移动片段。
- 所有素材引用可解析，文件大小与校验值一致，视频引用完整原文件；先前已经被裁短的文件如实记录可恢复范围。
- 字幕遵循指定的源时间或成片时间，不改变文字或断句。声音只按清单启用，不产生未经指定的重复人声。
- 必需效果不支持时，输出明确阻塞，不将缺效果的草稿标为完整转换。

## 应用内操作

在独立测试草稿或测试副本上进行会改变工程的操作，并记录测试前后状态。最终交付工程保留用户原清单的时间线。

1. 打开完整草稿，核对媒体链接、时间线首尾和代表性轨道位置。
2. 修改一条原生字幕的文字与位置，保存、关闭并重新打开，核对修改。
3. 选择源素材两侧均有余量的片段，向前和向后拖边，检查新增画面及指定声音关系。静音片段仍应遵循静音设置。
4. 对使用预制图形或透明视频的样本，检查移动与缩放行为；检查透明边缘及提示框是否残留旧镜头内容。
5. 对支持的局部效果，查看作用区域内外的显示；JSON 参数存在不能替代实际图像结果。
6. 如测试路径映射，在新位置重新绑定后检查媒体身份及可播放状态，保留原素材和原草稿。

## 证据记录

分别记录结构检查、应用打开、编辑保存重开、声音试听和画面观察的 `passed`、`failed` 或 `not_run`，附环境、工程路径和证据位置。可播放预览无法证明文字可改；静态截图无法证明听过声音。自动脚本结果与人工或 UI 检查结果分开呈现。

## 字幕联动回归

- 同批至少两条原生字幕：修改第一条字号，第二条同步，文字内容保持独立。
- 同时间线加入普通标题：字幕改样式后，标题保持原样。
- 关闭字幕联动后只修改一条：另一条保持原样；保存重开后再次验证开关与分组。
- 输入字幕样式不同：构建时保留不同样式；只在用户应用内实际修改时产生联动。
- 旧 text 清单保持普通文字；subtitle 的源时间换算、切点与音画关系仍通过历史回归。
- 对缺少group_id、错误材料类型、批次错并及UI样式错配的草稿，验证器应拒绝。
