# 声画编辑单元

适用于同期口播、对白、全屏人物切换小窗，以及要求保留字幕／画面关联的草稿。验收目标：用户拖动主要口播片段时，其人声与当前可见人物仍是同一时刻，无需再手动拖动另一条轨道补齐。

## 转换前先确定归属

在转换说明中列出主片段、声音来源、当前人物呈现及需要随动的字幕。以下检查属于 Agent 对素材和方案的语义检查；现有 `converter.py check` 只验证其支持的字段与结构，不会自动识别导出的 WAV 是否来自某段口播，也不会建立永久片段绑定。

### 同期声音

- 默认用视频片段自带的人声及明确音量。禁止默认生成“静音人物视频＋另一个独立人声音轨”的草稿结构。
- 背景音乐、音效和真正独立录制的旁白可分轨。一个从人物视频导出的 WAV，即使经过降噪或响度处理，仍属于该视频的同期声音。
- 上游已处理声音时，优先接收带有处理后声音的视频派生素材，要求源范围、速度、声画偏移和前后余量有明确记录；本转换 Skill 不自行重混或封装素材。上游只给了拆出的处理音频时，将带声素材或已验证的关联方案列为缺项，不擅自改回原声，也不把独立音轨当作默认完成。
- 用户明确要求音画分离或保留独立同期音轨时，遵从该指令并说明编辑影响。泛称多图层或已有中间文件包含独立 WAV，都不能代替该明确决定。

### 全屏人物与圆形小窗

优先顺序：

1. 同一人物主轨片段承载全屏／小窗的不同呈现，并保留同期音频。主轨人物形态变化时，持续沿用同一源时间映射。
2. 输入已经提供全屏与小窗两个确定素材时，在人物主轨按已定区间替换；小窗素材应包含对应同期声音及可追溯源映射。背景和演示层按明确构图放置，实际核对覆盖关系。
3. 确需独立人物小窗轨时，使用当前版本已验证的关联／组合能力，并在测试草稿中证实主轨单独移动后人物、声音及字幕一起跟随。只勾选联动范围不算验收完成。

不要同时保留无实际关联的全屏人物、另一条人物小窗和第三条同期音轨，让它们仅靠初始时间码对齐；这会让后续移动、裁切或替换留下不同步的副本。

用户明确要求人物小窗保持独立、无需随主轨移动时，保留该独立层并说明需单独维护其时间；不以默认关联规则拒绝这种输入。要求人物层独立也不自动授权拆出同期声音，声音归属仍按前节处理。

本优先顺序不增加转换器能力。原生圆形蒙版、关键帧、组合、主轨指定和跨轨绑定仍以当前支持范围与本次应用验证为准。所需主轨层级或关联无法可靠表达时，报告该具体能力缺项，不虚构字段，不静默改成独立浮层，也不擅自预渲染。上游明确提供的预制素材可以作为输入，不能因此承诺其内部蒙版或文字可编辑。

## 分清三种关系

- `subtitle_sync` 和字幕材料的批次标识：统一字幕样式。
- 字幕 `clip_id` 与源时间换算：建立草稿初始时间位置。
- 时间轴联动／组合：决定用户后续编辑时哪些片段一起移动，必须在剪映内验证。

前两项不能充当第三项的证据。主轨移动通过，也不能外推为删除、分割、拖边或变速后仍自动正确。

## 最小应用验收

在独立测试稿中选一个含字幕、同期人声、人物小窗和背景的代表区间：

1. 记录各对象原始起止位置及同一时刻的人脸画面。
2. 只选主口播片段，移动到一个明确的新位置，例如后移 1 秒；不同时框选其余轨道。
3. 核对人声、当前人物及应随动字幕的位移相同，源帧与嘴型时刻不变；独立背景是否随动按输入约定判断。
4. 保存重开后再看一次；仅在测试稿中撤销或复位测试动作。
5. 分别记录移动、删除、分割、拖边和变速的实际验证状态。用户只要求移动时，不扩大到无关破坏性测试，但其余项目保持未验证。

工具拖动未真正改变位置、只看到了开启的开关、或无法听到声音时，标明对应部分未验证，不能写成已绑定或声画同步已通过。
